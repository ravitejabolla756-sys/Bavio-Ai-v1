# Integrations

The implementation contains provider adapters for Twilio telephony, Deepgram/Sarvam speech recognition, ElevenLabs/Sarvam/OpenAI speech synthesis, Cerebras/Groq/OpenAI/Sarvam language models, Supabase database/auth/storage, Resend email, and Dodo billing events.

Integration availability depends on server configuration, credentials, provider account, country, and selected voice stack. A code adapter is not a guarantee that the integration is enabled. Contact `[SUPPORT_EMAIL]` for deployment-specific availability.
