# Getting Started with Bavio

1. Create and verify an account.
2. Complete Workspace and Agent setup.
3. Configure Knowledge and a Phone Number/provider path where available.
4. Review the Agent greeting, language, voice, and instructions.
5. Test the configured voice path before directing real callers.
6. Review Conversations, Leads, Actions, and Workflows in the dashboard.

Availability depends on account configuration, provider credentials, country, phone inventory, and billing state. This guide does not promise a particular provider or number.
