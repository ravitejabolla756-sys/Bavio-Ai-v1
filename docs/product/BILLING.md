# Billing

Bavio contains plan, subscription, usage, minutes, top-up/overage, and billing status concepts. The backend includes a Dodo payment webhook path and a retired Razorpay order path. Exact production pricing, taxes, renewal, refund, and proration terms are not established by this repository audit.

See [Billing and Subscription Terms](../legal/BILLING-SUBSCRIPTION-TERMS.md) and [Refund and Cancellation Policy](../legal/REFUND-CANCELLATION-POLICY.md) for unresolved commercial placeholders.
