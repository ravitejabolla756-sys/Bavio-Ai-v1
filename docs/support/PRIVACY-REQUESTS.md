# Privacy Requests

Send access, correction, deletion, export, restriction, or objection requests to `[PRIVACY_EMAIL]`. Include enough information to identify the Workspace and request without sending full credentials or unnecessary caller content.

Bavio may need to coordinate with the customer because the customer determines the purpose and authority for many caller records. The repository does not establish an automated self-service deletion/export flow for every category. Identity verification, response deadline, applicable exemptions, and data-return format require legal configuration.

For security incidents use `[SECURITY_EMAIL]`; for operational support use `[SUPPORT_EMAIL]`.
